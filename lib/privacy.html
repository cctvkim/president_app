개인정보처리방침

본 앱은 이용자의 개인정보를 소중히 여기며, 관련 법령을 준수합니다.

1. 수집하는 정보

본 앱은 다음과 같은 정보를 처리할 수 있습니다.

  • 기기 식별 정보(UUID)
  • 광고 식별자 (Google AdMob을 통한 광고 제공 목적)
  • 게시판 이용 시 작성한 게시글 및 댓글 내용
  • 앱 내 설정 정보 (폰트 크기 등)

2. 수집 목적

  • 게시판 기능 제공
  • 서비스 운영 및 개선
  • 광고 제공 (Google AdMob)
  • YouTube 콘텐츠 표시

3. 제3자 서비스 사용

본 앱은 다음 외부 서비스를 사용할 수 있습니다.

  • Google AdMob
  • YouTube Data API
  • AWS 서버 (게시판 기능)

4. 데이터 보관

게시글 및 댓글 데이터는 서버에 저장될 수 있습니다.
사용자 설정 정보는 기기 내부에 저장됩니다.

5. 이용자의 권리

사용자는 앱 삭제를 통해 로컬 데이터를 제거할 수 있습니다.
게시글 삭제 요청은 관리자에게 문의할 수 있습니다.
